# 一、先搞清面试流程（知道节奏就不慌）

```
第 1 轮  自我介绍          1–2 分钟      ← 决定第一印象，必须背到不用想
第 2 轮  介绍你的项目       10–20 分钟    ← 整个面试【80% 的时间】在这里
第 3 轮  追问细节 / 八股    10–20 分钟    ← 从你的项目往深处挖
第 4 轮  软问题 + 反问      5 分钟
```

**关键认知：**

> **面试官不会按题库问你，他会顺着你的项目往下挖。**
> 所以你要准备的不是"答案库"，是**"把项目讲清楚的能力"** —— 讲清楚了，他挖的地方你都知道；讲不清楚，他就会问到你不会的地方。

**这就是为什么先练这两块。**

# 三、项目讲解（2 分钟讲一个，这才是重头）

## ⭐ 万能四段式（所有项目都套这个）

```
① 一句话说清"这是什么"（≤15 字，别铺垫）
   例："这是一个 STM32F407 的智能循迹避障小车。"

② 硬件/技术构成（谁跟谁配合）
   例："两个直流电机 + L9110S 双 H 桥驱动，两路 TCRT5000 红外管做循迹，
        HC-05 蓝牙做遥控，主控是 F407。"

③ ⭐ 难点 + 我怎么解决的（面试官在听的就是这一段）
   现象 → 排查 → 根因 → 解决 → 验证

④ 结果（能验证的，不是形容词）
   例："用串口助手逐条发指令，转向、循迹、断线停车都验证通过。"
```

> **第③段是加分项。** 有难点的项目听起来才是真做过；没有难点的项目听起来像抄的。

## ⭐⭐ 项目③：智能循迹避障小车（你最熟，优先练这个）

**为什么优先**：这是你真动手调过的，细节问不倒你，先把它讲成"肌肉记忆"。

### 逐字稿（约 2 分钟）

> 这是一个基于 STM32F407 的智能循迹避障小车。
>
> 硬件上两个直流电机配 **L9110S 双 H 桥**驱动，前面左右各一路 **TCRT5000 红外对管**做循迹，**HC-05 蓝牙**模块做遥控。
>
> 软件主要三块。**电机**用定时器出 PWM，调占空比做差速转向——前进、后退、左右转、原地转，都是两个电机的转速组合出来的。**循迹**是两路红外组合判断：左边压到黑线就左转修正，右边压到就右转，两边都在线上就直行。**遥控**这块是我花时间最多的——
>
> 一开始我在串口中断里直接解析蓝牙指令，结果主循环一忙就丢指令。后来改成**中断里只把字节塞进环形缓冲，解析放到主循环**，读写指针各自前进、写到末尾绕回开头，不需要搬数据。
>
> 另外加了两个保护：不认识的字符直接丢弃重新同步，防止误触发；**超过 10 秒没收到指令就自动停车**，防止信号断了小车一直往前冲。
>
> 最后用串口助手逐条发指令，验证了转向、循迹和断线停车都正常。

### 🔑 关键词提示（忘词看这个，别看句子）

```
F407 → L9110S 双H桥 → TCRT5000 两路 → HC-05
PWM 差速 → 中断收字节 / 主循环解析 → 环形缓冲 → 10 秒超时停车
```

### 必被追问的 6 个（答案都要能脱口而出）

| 追问 | 一句话答 |
|---|---|
| **为什么用环形缓冲，普通数组不行吗** | 环形读写指针各自前进、写完绕回开头，**不用搬数据**；普通数组取完要 `memmove` 到开头，那是 O(n) 拷贝还阻塞 |
| **缓冲满了怎么办** | 置溢出标志 + 计数，主循环检测到就丢这一帧并重新同步帧头 |
| **10 秒超时为什么需要** | 蓝牙断了（超距/没电/模块掉线）小车会保持最后指令一直冲，很危险 |
| **超时判断放哪** | **放主循环**，不能放中断——中断里不能做长期计时判断 |
| **H 桥为什么能正反转** | 两组开关交叉导通改变电流方向，就改变了转向；换向要留死区防止上下桥直通短路 |
| **PWM 频率怎么选的** | 太低电机会叫、抖动；太高开关损耗大。取 10–20kHz 避开人耳听觉 |

## ⭐ 项目①：VisionPro + C# 工业视觉检测上位机

### 逐字稿（约 1.5 分钟）

> 这是用 **Cognex VisionPro 9.0 加 C# WinForms** 做的工业视觉检测上位机，一共三个检测 Demo。
>
> **方体物料**：把骰子图像二值化后，用 **CogBlob** 统计亮点连通域，亮斑个数就是点数，7 颗骰子一共 28 点。
>
> **线性物料**：先用 **CogPMAlign** 做模板匹配定位，再用 **CogFixture** 跟随这个坐标，保证工件位置变了参数也不用改；然后 7 路 **CogColorMatch** 分别识别网线颜色。
>
> **金属物料**：把 3 个 CogPMAlign 封装进一个 **CogToolBlock**，按识别出的面值换算总金额。
>
> C# 那边用 `CogSerializer` 加载 `.vpp` 作业，把图像塞进输入、`Run`、再从输出读结果。用 ToolBlock 封装的意义是**算法和界面解耦**——换算法不用改界面代码。
>
> 三个结果我都跟人工核对过，是一致的。

### 🔑 关键词

```
VisionPro 9.0 / C# WinForms / CogBlob 点数 28 / PMAlign→Fixture→7×ColorMatch / ToolBlock 封装 / .vpp 加载
```

### 必被追问的 5 个

| 追问 | 一句话答 |
|---|---|
| **CogPMAlign 干什么的** | 模板匹配，学一个模板后在图里搜最相似位置，输出坐标和角度 |
| **CogFixture 起什么作用** | 把 PMAlign 输出的坐标作为新原点/角度，后续工具跟着走，实现"位置无关" |
| **CogBlob 怎么数出点数的** | 二值化分离亮点，统计连通域个数；噪点用面积上下限过滤 |
| **ToolBlock 为什么能解耦** | 把多个工具封成黑盒，对外只暴露输入输出，界面只管输入输出 |
| **C# 怎么调 .vpp** | `LoadObjectFromFile` → 塞图像到 Inputs → `Run()` → 读 Outputs |

## ⚠️ 项目②：嵌入式 Linux 智能家居控制系统（有风险，先看提示）

> **⚠️ 先自查**：这个项目的技术骨架本鱼是从同学简历搬的。**如果你没真跑过，别硬讲"我写了驱动"** —— 面试官追问一句 `copy_to_user` 你就露了。
> **保守说法**：把"我写了串口驱动"改成"**我在这个项目里负责显示和采集部分，驱动部分是调通现成的**"。

### 逐字稿（约 1.5 分钟，保守版）

> 这是在 Linux 上做的智能家居控制系统，用 C 写。
>
> **显示**用 framebuffer：`open("/dev/fb0")` 之后用 **mmap** 把显存映射到用户空间，直接往映射地址写像素就能显示图片，省掉一次 `read` 拷贝——大块图像数据用 mmap 效率高得多。
>
> **交互**是读触摸屏设备的事件，解析出坐标后做界面点击和滑动。
>
> **数据采集**是串口读 **GY39** 的温湿度光照和 **MQ2** 的烟雾值，实时刷到 LCD 上；亮度用 **PWM** 调。
>
> 稳定性上专门做了资源释放：**每个 `open` 对应 `close`，每个 `mmap` 对应 `munmap`**——不然跑久了进程虚拟地址空间会被吃满，`mmap` 就返回失败了。

### 🔑 关键词

```
framebuffer /dev/fb0 + mmap 写像素 / 触摸事件解析 / 串口 GY39+MQ2 / PWM 调光 / open-close、mmap-munmap 成对
```

### 必被追问的 5 个

| 追问 | 一句话答 |
|---|---|
| **mmap 为什么不直接用 read** | read 每次都要把数据从内核拷到用户空间；mmap 直接映射，读写就是访问内存 |
| **mmap 用完不释放会怎样** | 占进程虚拟地址空间，频繁映射不释放会耗尽，`mmap` 返回 `MAP_FAILED` |
| **framebuffer 怎么画一个像素** | 偏移 `(y * xres + x) * (bpp/8)`，往映射地址对应位置写 RGB |
| **串口在 Linux 下要不要特殊设置** | 要设成 raw 模式（关掉行缓冲、回显、特殊字符处理），否则收发二进制会出错 |
| **怎么证明长时间稳定** | 跑一整夜看 RSS 有没有持续上涨、有没有崩、数据有没有跳变 |

## 如果面试官问"你负责哪一部分"

**不要答"都是我一个人做的"**（显得假），也别过度谦虚。这样答：

> 这个项目里我主要负责 **XX 和 XX**（举两个具体模块）。硬件搭接和 XX 部分是跟着课上做的，但 XX 的代码和调试是我自己完成的。

**具体化 + 划清边界 = 可信度。**

# 四、卡壳急救（这三句能救你）

**① 被问到不会的技术点**
> "这块我**没有实际做过**，但我的理解是……（说你能推的部分）。如果有机会我很想补上。"

**② 被问到项目里记不清的细节**
> "具体数值我得翻代码确认，但思路是……（讲思路）"
> ❌ 别说"我忘了" —— 说"需要确认数值"，这是正常的工程态度。

**③ 被他挖到你没想过的深层问题**
> "这个问题我当时没考虑到，我现在的想法是……（讲你的推理）"
> **诚实 + 现场推理，比硬编答案强得多。**

# 五、练法（3 天，每天 20 分钟）

```
第 1 天  自我介绍
  ① 照着逐字稿念 2 遍（念出声，不要默读）
  ② 关掉稿子，用【关键词提示】讲 3 遍，录音
  ③ 听录音，改掉"嗯、那个、然后就是"

第 2 天  项目③ 小车（最熟的那个）
  ① 照逐字稿念 2 遍
  ② 只看关键词讲 3 遍，录音
  ③ 自己给自己出追问（上面那 6 个），口头答

第 3 天  项目① + 项目②
  同上。练完把三个项目连着讲一遍（模拟真实面试）
```

**判断标准：不看稿、2 分钟、中间不停顿超过 2 秒 —— 就算过了。**
